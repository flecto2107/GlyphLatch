# GlyphLatch

Локальный менеджер шрифтов для Windows 11 x64. Собирайте шрифты в папки и наборы, сравнивайте начертания и временно включайте нужные в Windows. Исходные файлы остаются на месте.

## Установка

1. Откройте [последний релиз](https://github.com/flecto2107/GlyphLatch/releases/latest) и скачайте файл `GlyphLatch-Setup-…-win-x64.exe`.
2. Запустите установщик. Права администратора и отдельная установка .NET не требуются.
3. Откройте GlyphLatch из меню «Пуск». Для запуска без установки скачайте `GlyphLatch-Portable-…-win-x64.zip`, распакуйте архив и откройте `GlyphLatch.exe`.

Перед обновлением выберите **«Закрыть GlyphLatch»** в трее.

## Как пользоваться

- **Добавляйте шрифты.** Кнопка **«Добавить»** слева открывает импорт файлов TTF, OTF и папок с диска. Можно также перетащить файлы или папку из Проводника. Если открыт набор или папка, импорт добавляет шрифты туда.
- **Смотрите образцы.** Поиск и переключатели латиницы, кириллицы, цифр и своего текста находятся над списком. Нажмите на гарнитуру, чтобы раскрыть начертания. Кнопка **«Глифы»** над списком показывает символы выбранного шрифта.
- **Включайте шрифты.** Нажмите индикатор слева от начертания. Зелёный означает, что GlyphLatch включил шрифт в Windows. После включения можно переоткрыть список шрифтов в редакторе.
- **Сравнивайте в песочнице.** Выберите начертания для заголовка, подзаголовка и абзаца. Режим A/B показывает две версии макета с общими текстом и размерами.
- **Выходите через трей.** Крестик скрывает окно. Команда **«Закрыть GlyphLatch»** завершает приложение и снимает его временные регистрации.

GlyphLatch работает офлайн. Библиотека и настройки хранятся на компьютере в `%LOCALAPPDATA%\GlyphLatch` и сохраняются при удалении приложения. Номер версии указан внизу боковой панели.
